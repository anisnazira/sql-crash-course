# SQL 30 Hours Crash Course 🚀
> One query at a time.

This repository documents personal SQL learning progress  from basic SELECT statements to advanced analytical queries. Each folder represents a specific topic with example `.sql` scripts and short notes.



## 📘 Structure

| Folder | Topic | Notes |
|--------|--------|--------|
| `0_intro` | Basics of SQL, database concepts | [View Notes](0_intro/notes.md) |
| `1_querying_data` | SELECT, WHERE, ORDER BY | [View Notes](1_querying_data/notes.md) |
| `2_data_definition` | CREATE, ALTER, DROP (DDL) | [View Notes](2_data_definition/notes.md) |
| `3_data_manipulation` | INSERT, UPDATE, DELETE (DML) | [View Notes](3_data_manipulation/notes.md) |
| `4_filtering_data` | Filtering with WHERE, LIKE, IN | [View Notes](4_filtering_data/notes.md) |
| `5_combining_data` | Joins, subqueries, unions | [View Notes](5_combining_data/notes.md) |
| `6_row_level_functions` | String, date, numeric functions | [View Notes](6_row_level_functions/notes.md) |
| `7_aggregation_analytics` | GROUP BY, HAVING, window functions | [View Notes](7_aggregation_analytics/notes.md) |
| `8_advanced_sql` | CTEs, views, indexes, transactions | [View Notes](8_advanced_sql/notes.md) |
